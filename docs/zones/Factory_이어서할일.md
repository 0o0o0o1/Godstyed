(`PreloadAsync`는 편집 모드에서 정상 이미지도 Failure로 나와서 판단 기준으로 못 씀 → 화면으로 확인)
8. **사용자 지시: Studio에서 직접 플레이(캐릭터/NPC 걷기) 테스트는 하지 말 것** (2026-11-18). 경로·충돌은 편집 모드 레이캐스트·충돌 파트 수치로 확인하고 "플레이 테스트 안 함"이라고 보고.
