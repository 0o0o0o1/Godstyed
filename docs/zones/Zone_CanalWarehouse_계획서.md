## 2. 컨셉 & 스토리

**"마지막 구호선이 오지 않은 부두"**

- 붕괴 초기, 이 운하 부두는 **구호 물자 집결지**였다. 컨테이너로 바리케이드를 치고 생존자들이 버텼지만 결국 함락됨.
- 지금은 녹슨 크레인, 무너진 컨테이너 탑, 반쯤 가라앉은 바지선만 남아 있다.
- 환경 스토리텔링 요소
  - 컨테이너 위 생존자 캠프 흔적 (텐트, 깡통, 매트리스, 꺼진 드럼통 화로)
  - 컨테이너에 스프레이 낙서: "NO SHIP COMING", 날짜 카운트 표시(////)
  - 크레인 붐 끝에 매달린 채 기울어진 컨테이너 (바람에 삐걱이는 소리)
  - 창고 벽의 구호 물자 배급 안내판, 찢어진 군용 방수포
  - 운하에 떠 있는 부유물, 기름막

### 분위기 키워드
녹(Rust) · 바랜 원색 컨테이너 · 젖은 콘크리트 · 안개 · 금속 삐걱임 · 갈매기/까마귀

### A. 크레인 부두 (랜드마크)
- **STS 안벽 크레인 #1** — 위치 약 (-220, 0, 625)
  - 다리는 Lot_054 위에 서고, 붐은 북쪽(-Z)으로 운하 위로 뻗음
  - 높이 약 **120~130 스터드** (존 상한 140 안쪽), 다른 존에서도 보이는 실루엣
  - 구성: 4개 다리 + 가로 빔 + 기계실(머신하우스) + 운전실(캡) + 붐 + 매달린 스프레더 & 컨테이너
  - 올라갈 수 있게 할 경우: 다리 안쪽 사다리 → 중간 플랫폼 → 기계실 (최상단 루트 1개)
- **쓰러진 크레인 #2** — Lot_039 부근
  - 붐이 운하를 가로질러 쓰러져 있음 → **임시 다리** 역할 (위험하지만 빠른 루트)
  - 붐 위에 떨어진 컨테이너 1~2개, 찢어진 철골
- 크레인 레일(운하와 평행), 계류 볼라드, 타이어 펜더, 녹슨 체인

### B. 컨테이너 야드
- **Lot_056 (남쪽, 271×134)**: 정돈된 적치 블록 → 그 위를 RTG 갠트리 크레인이 가로지름
  - 블록 사이 통로 폭 **16~20 스터드** (차량 크기 기준)
  - 1단/2단/3단을 섞어 높이차 → 위로 올라가는 동선(계단 컨테이너, 비계, 쓰러진 컨테이너 경사로)
- **Lot_055 (북쪽, 271×112)**: 무너지고 흩어진 구역
  - 넘어진 컨테이너 탑, 리치스태커가 컨테이너를 든 채 멈춤, 트럭+샤시
  - 생존자 바리케이드 (컨테이너 + 모래주머니 + 철조망)
- **골목 (Z 864~876)**: 두 야드를 가르는 직선 통로 → 저격 라인이 되므로 중간에 엄폐물 배치
- 일부 컨테이너는 **문이 열려 있어 내부 진입 가능** (파밍 지점)

### C. 메인 창고
- 외형: 골판 금속 벽 + 철골 트러스 지붕, 한쪽 지붕 붕괴로 빛이 들어옴
- 내부: 팔레트 랙, 지게차, 구호물자 박스, 메자닌 사무실(2층)
- 출입구: 동쪽 하역 도크(셔터 3개, 1개만 열림) / 서쪽 운하 쪽 비상문 / 지붕 구멍
- 운하 쪽 외벽에 캣워크 → D구역·운하로 연결

### D. 서쪽 강변
- 소형 정비고, 원통형 연료탱크 2~3개, 펜스
- 감시탑 1개 (A구역 크레인과 서로 견제하는 저격 포인트)
- 운하 아래로 내려가는 계단 / 선착장

### E. 운하 수로
- 운하 바닥(Y ≈ -14) 가장자리 보행 턱 → 다리 밑으로 몰래 이동
- 반쯤 가라앉은 바지선 + 기울어진 컨테이너 (점프로 건너기)
- 물은 얕게(무릎~허리) 해서 이동은 가능하지만 느리게

## 8. 성능 기준

- 이 존 신규 파트 목표: **3,500개 이하** (현재 맵 전체 약 27,600개)
- 컨테이너·크레인은 MeshPart/모델 재사용, 골판 디테일은 텍스처로
- 장식용 작은 파트는 `CanCollide = false`, `CastShadow = false`, `CanTouch/CanQuery = false`
- 복잡한 메쉬는 `CollisionFidelity = Box` 또는 `Hull`
- StreamingEnabled 켜져 있음 →
  - 크레인 #1은 멀리서도 보여야 하므로 `ModelStreamingMode = Persistent` 검토 (단, 파트 수 적은 버전으로)
  - 컨테이너 묶음은 `Atomic`
- 지면 아래 / 맵 밖으로 빠지는 틈 없는지 확인 (특히 운하 벽과 바지선 주변)

## 9. 결정이 필요한 것

1. **크레인을 플레이어가 올라갈 수 있게 할까?** (추천: STS 1기만 올라갈 수 있게)
2. **운하에 들어갈 수 있게 할까?** (추천: 얕은 물로 이동 가능, 대신 느리게)
3. **좀비/적 NPC가 있는 게임인가?** → 있다면 NPC 이동 경로(통로 폭) 고려 필요
4. **잠긴 냉동 컨테이너(열쇠 시스템)** 넣을지
5. 이 존 전용 조건부 탈출구(예: 크레인 신호탄)가 필요한지
