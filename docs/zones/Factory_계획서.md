## 4. 분위기 규칙

- 색: 녹슨 철(Slate 갈색), 그을린 벽돌(코크스로), 바랜 산업 노랑(크레인·난간), 회색 콘크리트. **CorrodedMetal은 이 게임에서 분홍빛으로 보이므로 쓰지 않음** → Slate / Metal / Plastic.
- 연기·증기: 굴뚝·냉각탑·소화탑에 Smoke/ParticleEmitter (성능 상한 정해서).
- 조명(6단계, 사용자에게 먼저 물어볼 것): 회갈색 스모그, 낮은 해, 공장 안 주황 작업등. 이 place는 도시와 따로이므로 Lighting을 바꿔도 도시에 영향 없음(단, 같은 universe라 스크립트 공용 → 조명 스크립트 확인).
- 이야기: "구호 물자 부두"(운하 존)와 이어지는 "멈춘 제철소" — 꺼진 용광로, 굳은 쇳물, 버려진 작업복·안전모, 대피 안내판.

## 5. 성능 예산

- 구역당 BasePart ≤ 1,500 (메쉬 위주), 맵 전체 신규 ≤ 12,000.
- 대형 구조물(용광로, 냉각탑)은 메쉬 + 단순 충돌 프록시. `ModelStreamingMode` 검토.
- 파티클: 동시에 보이는 연기 이미터 ≤ 15.

1. 블록아웃: 구역 A~H + 공통 배관 다리를 색깔 있는 상자로 (`Workspace.FactoryBlockout`) → 위에서 스크린샷 → 사용자 확인

3. 중간 에셋: 가스 홀더, 스태커-리클레이머, 배관 다리 키트, 굴뚝, 컨베이어 키트
4. 바닥 마감: 공원·주차장 → 산업 부지(재질·잔해), 야적 더미 지형
5. 소품·디테일·낙서
6. 조명·연기
7. 태그(LootSpawn, ClimbPoint) — 운하 창고 존 7단계와 함께
8. 테스트·최적화
